Privacy in one paragraph隐私，一段话说完

OCR runs on your device; images never leave it, and neither do comic titles or URLs. Only the recognised text is sent for translation, and only to the backend you pick. The hosted service stores an email address, a daily page counter and a subscription expiry — its database has no column that could hold an image, a URL or any text. There is no analytics SDK and no advertising SDK in the app. OCR 在设备上完成，图片不出手机，作品名称与地址也不上传；只有识别出的文字会发给 你选择的后端。云服务只保存邮箱、每日页数计数与订阅到期时间——它的数据库里 没有任何一列能装下图片、地址或原文。App 内不含任何统计或广告 SDK。

FAQ常见问题

Does it come with any sources?它自带源吗？

No. It bundles, recommends and hosts none. You decide what to add, and you are responsible for using it lawfully. 不带。不内置、不推荐、不收录任何源。加什么由你决定，也由你自行确认是否合法使用。

Is translation free?翻译收费吗？

It can be entirely free: paste your own OpenAI-compatible API key, or use on-device translation. The hosted service has a free daily quota and an optional subscription. 可以完全免费：自备一个 OpenAI 兼容的 API Key，或使用设备端翻译。官方云服务每天有免费额度，订阅是可选项。

Where do I pay?在哪里付款？

On this website. There is no checkout inside the app and no payment SDK — the app only ever opens a web page. 在本网站上。App 内没有收银台、不接任何支付 SDK——它只会打开一个网页。

Can I delete my account?可以注销账号吗？

Yes, from Settings → Account & Cloud → Delete account. It removes the account, its quota counters and its subscription records within 30 days. 可以。设置 → 账号与云服务 → 注销账号。账号、额度计数与订阅记录会在 30 天内删除。

Is this affiliated with any content site?它和某些内容站有关系吗？

No. It is a general-purpose reader, not affiliated with, endorsed by or connected to any content website, and it contains no third-party content. 没有。它是通用阅读器，与任何内容站点都没有隶属、背书或合作关系，也不包含任何第三方内容。

MangaTranslater is a general-purpose comic reader. It ships with no online sources and no third-party content. MangaTranslater 是通用漫画阅读器，不自带任何在线源，也不包含任何第三方内容。
